The lock question in a shared house comes up on most buy-to-let surveys I do. A landlord has a house of five rooms and a front door that eats keys: each new tenant means another copy, and each leaver means a conversation about whether the old one has been handed back. A push-button code lock looks like the answer. Change the code, and the problem goes away.

Sometimes it is. But a lock on a door in an HMO is a fire-safety item before it is a security item. The principle in the fire guidance for houses in multiple occupation is simple: anyone inside must be able to open the doors on the way out without a key and without knowing a code. That one sentence rules out half the code locks on the market, and it is why this guide treats the inside of the door as the first thing to check. The fire risk assessment cost guide covers the assessment that will look at it, and the HMO licence cost guide covers the licence conditions that can set it out.

How I judge a code lock for a shared house

Does the inside open without a key or code? This comes before everything else. A lever or thumbturn that always works from the inside is the standard. A lock that needs a key or code to get out, even a smart one, is the wrong answer on an escape route. Requirements are set by the local authority and the fire risk assessment, so check the licence conditions for your council.

Is it tested in a fire door? A lock cut into a fire door can weaken it. Look for BS EN 1634-1 test listings for the door thickness and fire period, and fit the intumescent kit that goes with them. A cheap lock in a fire door can undo the door.

Mechanical or electronic? A mechanical code lock has no battery, so nothing flat to find at a front door at 11pm. An electronic or smart lock offers remote code changes and tenant-specific codes, at the cost of a battery routine. In a shared house that churns tenants the second is easier to manage, if you actually do the routine.

Who knows the code? A code is shared in a way a key is not. One code on a front door is known to every past tenant unless you change it. Build a code change into the move-out checklist.

Does it fit the door? Doors in old houses are often 35mm to 44mm, sometimes thinner at the stile. Check backset, handing and thickness against the datasheet.

What actually matters — and what doesn’t

The inside of the door matters more than the keypad. Spend the time on the escape route. Walk out of the house from the furthest bedroom as if the lights were out, and see whether every door opens with one hand and no key.

Bedroom doors are their own question. A lockable room door is normal in an HMO, but the lock should be operable from inside without a key, normally with a thumbturn, and the door should still be a fire door. A code lock on a bedroom door that needs a code from the inside is a problem.

Insurance and the lock standard. Some home insurance policies set a standard for external door locks, commonly a five-lever mortice or a BS 3621 cylinder. A code latch alone may not meet it. Check the policy before swapping a front-door lock.

What salesmen push that doesn’t matter. Thousands of possible codes, which is academic when the code is shared, and a heavy-duty rating for a door used five times a day. The things to compare are free exit, fire listing and a battery routine you will actually follow. Questions I get asked

Can I put a code lock on an HMO front door? Yes, provided the inside of the door opens without a key or code, the lock is suitable for the door, and it meets any licence condition and your insurer’s requirements. The fire risk assessment is where this gets tested.

Are smart locks allowed in rented houses? There is no general ban, and the same escape rule applies. A smart lock that keeps a thumbturn on the inside is the better type for a rental, and it needs a clear process for who can add and remove access.

What is the difference between a code lock and a keypad lock? Mechanical code locks use buttons and have no electronics. Keypad locks are usually electronic. They are often sold under similar names, so check whether the lock needs batteries.

Do I still need keys? Normally yes. Most code locks have a key override, and a house needs a way in when a code or battery fails. Keep the override keys in a cabinet, not under a plant pot.
