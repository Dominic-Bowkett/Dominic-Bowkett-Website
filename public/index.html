008 / Software

Founder — iCalendar.app

I also build the booking software I use to run this practice.

Surveying is a driving job. Two appointments can sit an hour apart on paper and be impossible in practice. Every booking tool I tried only asked whether the diary was empty — never whether I could actually get there. So I built one that does.

iCalendar.app checks real driving times before it offers a client a slot — around the day’s existing jobs, the school run and being home for dinner. It takes card payments, raises the invoice and logs the mileage for the tax return. It runs my own diary, and it’s now used by other surveyors, energy assessors and mobile trades.
